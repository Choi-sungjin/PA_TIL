## 1. SLERP 검산 — 금요일에 못 끝낸 계산

지난주 마지막에 못 채운 항목이 이거였다. 항등 자세와 z축 $90^\circ$ 자세 사이를 $t = 0.5$ 로 보간하면 정확히 절반인 $45^\circ$ 가 나와야 한다.

```math
q_0 = (1, 0, 0, 0), \qquad q_1 = (0.7071,\ 0,\ 0,\ 0.7071)
```

두 쿼터니언의 내적이 $\cos\Omega$ 이므로 $\cos\Omega = 0.7071$, 즉 $\Omega = 45^\circ$ 다. 여기서 $\Omega$ 는 두 자세 사이의 각이지 회전각이 아니다.

```math
\mathrm{Slerp}(t=0.5) = \frac{\sin 22.5^\circ}{\sin 45^\circ}\,(q_0 + q_1) = (0.9239,\ 0,\ 0,\ 0.3827)
```

검산: $w = 0.9239 = \cos 22.5^\circ$ 이고 쿼터니언은 반각이 들어가므로 $\theta/2 = 22.5^\circ$, 곧 $\theta = 45^\circ$. 기대한 대로 정확히 절반이 나왔다. **$w$ 를 보고 바로 각도라고 읽으면 안 되고 두 배 해야 한다**는 걸 검산하면서 다시 확인했다.

### SLERP vs NLERP

성분을 그냥 선형 평균한 뒤 크기만 1로 정규화하는 방법(NLERP)도 있다. 그래프로 비교하니 차이가 뚜렷했다.

- **회전각 진행**: SLERP는 직선(등속), NLERP는 S자로 중간에서 빨라졌다 느려진다.
- **호 위의 중간 자세**: 같은 간격의 $t$ 를 넣었을 때 SLERP는 등간격으로 놓이는데, NLERP는 중앙에 몰린다.

각속도가 일정해야 하는 모터 제어에서는 SLERP를 써야 하는 이유가 이 그림 하나로 설명됐다.

### 이중 피복 — $q$ 와 $-q$ 는 같은 회전

쿼터니언에서 부호만 뒤집은 $-q$ 는 완전히 같은 회전을 나타낸다. 그래서 보간 전에 두 쿼터니언의 내적이 음수면 한쪽 부호를 뒤집고 보간해야 한다. 안 그러면 가까운 길을 두고 먼 쪽 호로 빙 돌아간다.

## 2. 쿼터니언 → 회전행렬

저장·보간은 쿼터니언으로 하고, 실제 좌표를 변환할 때는 회전행렬로 바꾼다. 공식은 $w, x, y, z$ 로 3×3 을 채우는 형태인데, 외우는 게 목적이 아니라 **둘이 같은 회전의 다른 표현**이라는 게 핵심이다. 쿼터니언은 표현이 콤팩트하고 보간이 쉬워서 저장·전송에 쓰고, 행렬은 벡터에 바로 곱할 수 있어서 계산에 쓴다.

## 3. 고유값·고유벡터 — 방향이 보존되는 벡터

일반적인 벡터에 행렬 $A$ 를 곱하면 방향이 돌아간다. 그런데 어떤 특별한 방향은 방향이 그대로 유지되고 크기만 $\lambda$ 배 된다.

```math
A\mathbf{v} = \lambda\mathbf{v} \qquad (\mathbf{v} \neq \mathbf{0})
```

"변환이 건드리지 못하는 방향"이라는 설명이 와닿았다. 공진, 안정성, PCA가 전부 여기서 나온다.

### 특성방정식 유도

이항하면 $(A - \lambda I)\mathbf{v} = \mathbf{0}$ 이 된다. $\mathbf{v} \neq \mathbf{0}$ 인 해가 있으려면 $A - \lambda I$ 가 특이행렬이어야 하고, 특이하다는 건 18강에서 본 대로 **행렬식이 0**이라는 뜻이다.

```math
\det(A - \lambda I) = 0
```

그래서 고유값 구하기가 다항방정식 근 구하기로 바뀐다. 검산은 근·계수 관계 그대로다 — 고유값의 합은 대각합, 곱은 행렬식.

```math
\sum_i \lambda_i = \operatorname{tr} A, \qquad \prod_i \lambda_i = \det A
```

### 손으로 푼 예제

```math
A = \begin{pmatrix} 4 & 1 \\ 2 & 3 \end{pmatrix}
```

$\det(A - \lambda I) = (4-\lambda)(3-\lambda) - 2 = \lambda^2 - 7\lambda + 10 = 0$ 이므로 $\lambda_1 = 5$, $\lambda_2 = 2$.

검산하면 합 $7 = \operatorname{tr} A$, 곱 $10 = \det A$ 로 맞는다. 각 고유값을 다시 넣어 풀면 $\mathbf{v}_1 = (1, 1)$, $\mathbf{v}_2 = (1, -2)$.

## 4. 회전축은 어디서 오는가 — 오늘의 핵심

여기가 오늘 제일 재미있던 부분이다. 회전축 위에 있는 벡터는 아무리 회전시켜도 제자리다. 즉 $R\mathbf{n} = \mathbf{n}$ 이고, 이건 $\lambda = 1$ 인 고유벡터라는 뜻이다.

**회전축 = 회전행렬의 $\lambda = 1$ 고유벡터.**

3차원 회전행렬의 고유값은 $\lambda_1 = 1$ (실수), $\lambda_{2,3} = \cos\theta \pm i\sin\theta$ (켤레복소수)로 나온다. 대각합은 고유값의 합이므로,

```math
\operatorname{tr} R = 1 + (\cos\theta + i\sin\theta) + (\cos\theta - i\sin\theta) = 1 + 2\cos\theta
```

정리하면 회전각이 대각합만으로 바로 나온다.

```math
\theta = \arccos\frac{\operatorname{tr} R - 1}{2}
```

$R_z(90^\circ)$ 로 확인해봤다. 이 행렬의 대각합은 $0 + 0 + 1 = 1$ 이므로 $\theta = \arccos 0 = 90^\circ$, $R\mathbf{n} = \mathbf{n}$ 을 풀면 $\mathbf{n} = (0,0,1)$ 로 z축이 나온다. 예상과 일치.

지난주에 배운 오일러 회전 정리("모든 3D 회전은 축 하나 + 각 하나")를 그때는 그냥 받아들였는데, 오늘 그게 고유값 문제의 결과라는 걸 알았다. **회전행렬에서 쿼터니언으로 변환하는 코드가 실제로 하는 일이 이 고유값 문제 풀이다.** 지난주와 오늘이 여기서 이어졌다.

## 5. 대각화 — 행렬이 가장 단순해지는 좌표계

고유벡터를 열로 쌓은 $P$ 로 좌표계를 바꾸면, 성분이 뒤섞여 복잡하던 $A$ 가 그냥 축별로 늘리고 줄이는 대각행렬 $\Lambda$ 가 된다.

```math
A = P\Lambda P^{-1}, \qquad A^k = P\Lambda^k P^{-1}
```

거듭제곱이 특히 편해진다. $A$ 를 $k$ 번 곱하는 대신 대각원소만 $k$ 제곱하면 끝이다. 미분방정식 $\dot{\mathbf{x}} = A\mathbf{x}$ 의 해도 고유값 지수함수의 합으로 나오고, 고유값 실수부가 모두 음수면 해가 0으로 수렴한다 — 제어공학에서 "극점이 좌반평면에 있어야 안정"이라는 말이 바로 이거였다.

## 6. 대칭행렬과 스펙트럼 정리

실수 대칭행렬($A = A^\top$)은 성질이 유난히 좋다.

- 고유값이 전부 실수
- 고유벡터끼리 서로 직교
- 항상 직교행렬로 대각화됨: $A = Q\Lambda Q^\top$

$Q^{-1} = Q^\top$ 이라 역행렬을 계산할 필요조차 없다. 공학에서 다루는 행렬은 대부분 대칭이라(응력 텐서, 관성 텐서, 공분산 행렬, 강성 행렬) 이 정리가 여기저기서 쓰인다.

### 주축 변환 예제

기울어진 타원 $5x^2 + 4xy + 2y^2 = 1$ 의 주축을 찾는 문제. 교차항 $xy$ 가 있으면 축이 기울어진 것이다. 이차형식 행렬을 세우면

```math
S = \begin{pmatrix} 5 & 2 \\ 2 & 2 \end{pmatrix}, \qquad \lambda^2 - 7\lambda + 6 = 0 \Rightarrow \lambda = 6,\ 1
```

고유벡터 방향으로 축을 돌리면 $6\tilde{x}^2 + 1\tilde{y}^2 = 1$ 로 교차항이 사라진다. 두 고유벡터가 직교한다는 것도 그림에서 확인됐다. 고등학교 때 배운 주축 변환이 사실 고유벡터 방향으로 회전하는 것이었다.

## 7. SVD — 어떤 행렬이든 회전·신축·회전

마지막은 특이값 분해다. 대칭도 아니고 정방행렬도 아닌 행렬조차 세 단계로 쪼갤 수 있다.

```math
A = U\Sigma V^\top
```

단위원이 $V^\top$(회전) → $\Sigma$(축별 신축) → $U$(회전)를 차례로 거치며 타원이 되는 그림이 직관적이었다. 특이값은 $A^\top A$ 고유값의 제곱근이다 — 대칭행렬에서만 되던 스펙트럼 정리를 임의의 행렬로 확장한 결과라고 이해하면 된다.

큰 특이값 몇 개만 남기면 행렬의 핵심만 남는 근사가 되고, 이미지 압축과 노이즈 제거가 이 원리다. 27강에서 배울 Kabsch 정합(두 점군 사이 최적 회전)도 SVD를 쓴다고 한다.

## 9. 막혔던 지점 / 메모

- **$\Omega$ 와 $\theta$ 를 헷갈렸다.** SLERP 식의 $\Omega$ 는 두 쿼터니언 사이의 각이고, 회전각 $\theta$ 와는 다른 값이다. 게다가 반각 때문에 $\Omega$ 는 회전각 차이의 절반이다. 검산할 때 이걸 구분 못 해서 한 번 틀렸다.
- **고유값 검산은 무조건 하자.** 합이 대각합, 곱이 행렬식. 2×2 는 근의 공식으로 풀다 부호를 자주 틀리는데 검산 두 줄이면 바로 잡힌다.
- **$\lambda = 1$ 이 회전축이라는 게 오늘의 연결고리.** 17~19강에서 회전행렬, 오일러각, 쿼터니언을 따로따로 배웠는데 전부 고유값 문제 하나로 묶였다.
- **대각합만으로 회전각이 나온다**는 게 실용적이다. 회전행렬 9개 성분을 다 볼 필요 없이 대각선 3개만 더하면 된다.
- SVD는 오늘 개념만 훑었고 손으로 풀지는 않았다. 27강에서 Kabsch로 다시 나온다고 하니 그때 제대로 볼 것.
